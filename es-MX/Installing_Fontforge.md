title: Instalación de FontForge
---

FontForge es un software libre, por lo que puedes descargar, compartir e instalar copias sin ninguna restricción de uso &mdash; tanto el uso comercial como el personal son bienvenidos.
Es una aplicación mantenida por la comunidad, y cualquiera puede contribuir al código fuente.

FontForge está disponible en paquetes de fácil instalación para los sistemas operativos Windows, Mac OS X y GNU/Linux.

### Instalación de FontForge en Windows

Existe una [guía de instalación](http://fontforge.github.io/en-US/downloads/windows/) para las versiones oficiales de Windows, preparada por Jeremy Tan.

### Instalación de FontForge en Mac OS X

Existe una [guía de instalación](http://fontforge.github.io/en-US/downloads/mac/) para las versiones oficiales de Mac, preparada por el Dr. Ben Martin.

### Instalación en GNU/Linux

El método más sencillo para conseguir FontForge en tu máquina Linux es utilizar el repositorio de paquetes de tu distribución Linux.

Existe una [guía de instalación](http://fontforge.github.io/en-US/downloads/gnulinux/) para las versiones oficiales de GNU/Linux.

### Instalación de versiones antiguas de FontForge

Los usuarios que necesiten una versión antigua de Fontforge pueden buscar versiones estables
[aquí](https://github.com/fontforge/fontforge/releases), y
[aquí](https://sourceforge.net/projects/fontforgebuilds/), y versiones anteriores a 2012
[aquí](http://sourceforge.net/projects/fontforge/files/fontforge-executables/).

## Compila tu propia versión desde GitHub

GitHub es un servicio de alojamiento de código fuente donde todo el mundo puede contribuir al desarrollo de un software.
Almacena el estado actual de desarrollo de la aplicación.
En algunos casos, tal vez porque quieras acceder a una característica que aún no está disponible en los paquetes de lanzamiento, puedes desear compilar tu propia versión desde GitHub.

Las instrucciones completas están en <https://github.com/fontforge/fontforge/blob/master/INSTALL.md>
